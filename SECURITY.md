# Sicherheit / Security

## Sicherheitsprobleme melden

Bitte veröffentliche vermutete Sicherheitslücken nicht zusammen mit Zugangsdaten in einem öffentlichen Issue. Kontaktiere den Repository-Eigentümer zunächst über das GitHub-Profil **GordenM82** und beschreibe nur die notwendigen Schritte zum Nachstellen.

Es besteht keine Zusage für bestimmte Reaktions- oder Behebungszeiten. NanoTwitchLeafs 4 ist ein privat gepflegtes Freizeitprojekt.

## Reporting security issues

Do not disclose suspected vulnerabilities together with credentials in a public issue. Contact the repository owner through the **GordenM82** GitHub profile first and include only the information required to reproduce the issue.

No particular response or remediation time is guaranteed. NanoTwitchLeafs 4 is a privately maintained spare-time project.

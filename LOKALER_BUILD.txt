NanoTwitchLeafs 3.2.0.5 – privater lokaler Build
=================================================

1. ZIP vollständig in den kurzen Ordner "C:\NTL" entpacken.
   Lange Pfade unter Downloads können ältere .NET-Buildwerkzeuge überfordern.
2. Optional die Datei "ServiceCredentials" aus der bisherigen
   NanoTwitchLeafs-Installation in diesen Ordner kopieren und in
   "ServiceCredentials.local" umbenennen.
3. BUILD_NTL.cmd doppelt anklicken.
4. Nach erfolgreichem Build liegt das fertige Paket hier:
   artifacts\NanoTwitchLeafs-3.2.0.5.zip

Benötigt wird Visual Studio 2022 oder Visual Studio 2022 Build Tools mit:
- .NET-Desktopbuildtools
- .NET Framework 4.7.2 Targeting Pack
- MSBuild

Falls BUILD_NTL.cmd meldet, dass MSBuild fehlt, muss zuerst Visual Studio
2022 Build Tools installiert werden. Bitte dann einen Screenshot der Meldung
schicken; anschließend kann genau die fehlende Komponente bestimmt werden.

Datenschutz:
- Es wird nichts veröffentlicht oder zu GitHub hochgeladen.
- ServiceCredentials.local wird von Git ignoriert.
- Die Datei wird ausschließlich lokal in das fertige Testpaket kopiert.
